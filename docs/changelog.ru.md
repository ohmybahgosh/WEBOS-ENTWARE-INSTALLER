# Список изменений

Изменения WebOS Entware на русском, для экрана «Что нового» в приложении.  Заголовки разделов (`### Added`, `### Changed`, `### Fixed`) остаются на английском, как в исходном [CHANGELOG.md](../CHANGELOG.md), где есть все версии: приложение переводит их само.

## [2.17.1] - 2026-11-22

### Fixed

- **Удаление разбирает и собственный корень Entware** на телевизоре без /opt (webOS 4–6), а не оставляет его пустую рамку в оперативной памяти до следующей перезагрузки.  Это делается снаружи рамки, когда внутри ничего не работает: сразу после удаления по SSH или при следующей проверке приложения после удаления, запущенного из него.  В `/tmp` и `/var/lib` ничего не остаётся, а проверки приложения после удаления не создают её заново.

## [2.17.0] - 2026-11-22

### Added

- **Теперь работают телевизоры без /opt (webOS 4, 5 и 6, модели 2018–2021 годов).**  В их прошивке нет `/opt`, а система только для чтения, поэтому установка останавливалась с ошибкой «This firmware has no /opt folder» ([#5](https://github.com/ohmybahgosh/WEBOS-ENTWARE-INSTALLER/issues/5), спасибо SiriosDev).  На таких телевизорах Entware теперь монтируется в собственном корне.  **Entware не находится в оперативной памяти:** он установлен во встроенное хранилище телевизора, как на любом другом телевизоре, и пакеты, настройки и файлы сохраняются после перезагрузки.  В оперативной памяти только небольшая рамка для него (tmpfs, куда подключены папки самого телевизора, и `/opt` для Entware), и загрузочный скрипт заново создаёт её после каждой перезагрузки.  В системе телевизора ничего не меняется.  Установщик, приложение, его фоновые задачи, загрузочный скрипт и входы по SSH попадают туда сами; для одной команды по SSH есть `sh /var/lib/webos-entware/webos-entware-root run COMMAND`.  Песочницы приложений туда не попадают, ничего смонтированное внутри не видно снаружи, а USB-диски видны, в том числе подключённые позже.  Проверено на прошивке webOS 6.5.3 (LM21A), запущенной в эмуляторе: установка, дополнение из Entware, перезагрузка, вход по SSH, doctor и удаление.  Новые тесты проверяют это при каждом push.

### Fixed

- **В README было написано, что webOS 4 и новее должны работать,** хотя webOS 4–6 до сих пор не работали.  Теперь они перечислены с описанием того, как это устроено.

## [2.16.1] - 2026-11-21

### Added

- **«Что нового» на вашем языке.**  После обновления приложения изменения показываются на русском или испанском, если приложение переключено на один из них, с заголовками «Добавлено», «Изменено» и «Исправлено», как в LG-USB-2-ETH0 и FW Block.  Переведённые списки изменений лежат в [`docs/changelog.ru.md`](changelog.ru.md) и [`docs/changelog.es.md`](changelog.es.md).
- **«Справка», «Что нового»** показывает изменения этой версии в любое время, а не только один раз после обновления.
- **Приложение показывает, что входит в обновление, до установки,** на своём языке, если в выпуске есть этот перевод.  Теперь каждый выпуск содержит свои списки изменений, которые проверяются по его SHA256SUMS, как и само приложение.

### Security

- **Выпуски подписываются, и приложение обновляется только до подписанного.**  `SHA256SUMS` каждого выпуска подписывается ключом проекта на компьютере автора, никогда на GitHub, а установщик проверяет подпись с помощью `openssl` по встроенному ключу (или его офлайн-резервной копии), прежде чем предложить, показать или установить обновление.  Каждый файл, который приложение берёт из выпуска, сверяется с этими подписанными контрольными суммами, поэтому выпуск, выложенный кем-то другим, не установится.  Ключи лежат в [`release-signing-key.pub`](../release-signing-key.pub) и [`SECURITY.md`](../SECURITY.md#release-signing), как в LG-USB-2-ETH0.

## [2.16.0] - 2026-11-20

### Added

- **Приложение для телевизора и панель для телефона на русском и испанском,** а также на английском.  Приложение следует языку телевизора, или язык можно выбрать в **«Справка»**, **«Язык»**; панель для телефона следует языку телефона.  Переведены дополнения, категории и советы в «Пакетах», справка по командам SSH, а также проблемы и заметки полной проверки на главном экране.  Журналы задач, сама полная проверка и отчёты для GitHub остаются на английском, как и по SSH.  Новый тест, `tests/check-i18n.js`, проваливает CI, если у какого-либо текста приложения или панели нет перевода.

### Changed

- **В меню приложения появились вкладки и более крупный текст,** как в LG-USB-2-ETH0, SSH Doctor и FW Block, чтобы его было удобно читать на небольшом телевизоре: **«Пакеты»** (обновления пакетов, пакеты, дополнения), **Entware** (обновление приложения, проверка и восстановление, перенос, удаление) и **«Справка»** (команды SSH, полная проверка и журналы, отчёты для GitHub, язык).  Кнопки высотой 40px вместо 27px, карточка состояния, всплывающие окна и экран «Пакеты» тоже стали крупнее.  Карточка состояния показывает главное, а nano, сертификаты и locate появляются, только когда им нужно внимание.  Приложение открывается на «Пакетах», или на Entware, если нужна установка, восстановление или обновление приложения.
- **Список во всплывающем окне никогда не показывает строку, обрезанную пополам:** он начинается с верха строки, а строка, которая не помещается, ждёт следующей прокрутки.

### Fixed

- **Удаление полностью убирает за собой:** перед удалением оно останавливает панель для телефона и все программы, ещё работающие из Entware (например, `tv serve` или tmux), чтобы ничего не продолжало работать из удалённых файлов.  Скрипты автозапуска, созданные `tv autostart`, отключаются (они используют `tv`, который удаляется вместе с Entware), но сохраняются, а его временные файлы в `/tmp` удаляются.  Чужая сессия SSH остаётся нетронутой.
- **Две задачи, запущенные в один момент, не могут выполняться обе там, где `mkdir` сообщает об успехе, проиграв гонку,** как это делает uutils coreutils с 0.8 по 0.10 (Ubuntu 26.04).  Блокировка задач и блокировка запуска теперь захватываются файлом, который может создать только один процесс, а не одним `mkdir`.
